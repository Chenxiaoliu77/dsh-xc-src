## DSH Tauri 桌面端运行验证

- 环境：Windows，Node 22.22.2，pnpm 11.7.0，cargo 1.98.1；依赖需先 `pnpm install`。
- 工作区快照无 `.git`，`crates/` 三个子模块为空，`git submodule update` 不可用；按 `.gitmodules` 补齐 electron-rs（Cargo.toml 固定 rev 025fe1a3）、tauri-runtime-electron、tauri-plugin-notifications，版本与 Cargo.lock 一致（0.1.0 / 0.1.0 / 0.5.0-rc.14）。
- `pnpm install` 的根 preinstall 会跑 `pnpx skills experimental_install`，被本机 node-safe-delete shim 拦截；用 `pnpm install --ignore-scripts` 绕过。
- 本机 `NODE_OPTIONS` 注入 sandbox 的 node shim，会传给应用的 pnpm 子进程并触发 SAFE_DELETE_BULK_CONFIRM_REQUIRED，内置插件安装失败；启动须 `env -u NODE_OPTIONS pnpm dev:desktop`。
- `~/.dsh.dev/.credentials.yaml.lock` 残留会让 dsh 启动报 atomic-write 超时，需清掉该锁。
- `pnpm dev:desktop`（devUrl 1420 + 壳层页 `<webview>`）内容区空白：主窗口 webview 用 `browser_host()` 创建，tauri-runtime-electron 的 BrowserGuests 会 preventDefault 所有非 lease 的 guest。
- 可用路径：`cargo build --no-default-features` 后直接运行 `target/debug/deepseek-harness-desktop.exe`（正式文档形态，壳层注入 shadow DOM），界面完整；内核服务在 3081。
- 首启会联网下载内核到 `%APPDATA%\dsh-tauri\dev\dependencies\dsh`（约 590MB）。
- 后台启动的 GUI 进程会在本轮对话结束时被回收（日志表现为 electron run loop finished + RUN_EVENT_EXIT），不是应用自身退出；需要长驻时由用户在自己的终端启动。
